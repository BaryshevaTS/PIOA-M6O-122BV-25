## Реализованный функционал
| Компонент | Описание |
|-----------|----------|
| `InMemoryDB` | Класс-хранилище с методами `create_table`, `create_record`, `select_record`, `update_record`, `delete_record`, `sort_records`. Все данные хранятся в оперативной памяти. |
| Валидация схем | Строгая проверка типов, обязательных полей, запрет лишних полей, блокировка `bool` вместо `int`, контроль отрицательных значений для числовых полей. |
| Сортировка | Метод `sort_records(field, descending)` поддерживает сортировку по любому полю схемы в возрастающем/убывающем порядке. |
| Защита состояния | Возвращаемые записи копируются через `copy.deepcopy()`, что предотвращает внешнюю мутацию внутреннего состояния БД. |
| TUI | Класс `DatabaseTUI` управляет консольным меню, валидирует пользовательский ввод, обрабатывает `float`/`int`/`str` через выделенные методы `_read_*`. |

Управление данными: Создание, чтение, обновление и удаление записей (CRUD).
Валидация:
Проверка типов данных (str, int, float).
Контроль обязательных полей.
Запрет на отрицательные значения для числовых полей.
Сортировка: Вывод записей по возрастанию или убыванию выбранного поля.
Инкапсуляция: Внутренние структуры данных (_tables, _schemas) скрыты. Доступ к ним осуществляется только через публичные методы (has_table, get_schema), что предотвращает нарушение целостности данных извне.
