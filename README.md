## ️ Различия между In-Memory и файловыми реализациями

| Характеристика          | `InMemoryDB`                     | `JsonDatabase` / `CsvDatabase`           |
|-------------------------|----------------------------------|------------------------------------------|
| **Хранение данных**     | Оперативная память (`dict`)      | Диск: файлы `.json` или `.csv` + `.json` для схемы |
| **Сохранение данных**     |  Данные теряются при выходе      |  Данные сохраняются между запусками    |
| **Скорость операций**   |  Максимальная (RAM)              |  Зависит от объёма данных и диска      |
| **Индексация**          | Не требуется (данные в памяти)   |  Поддерживается через `IndexedDatabaseMixin` |
| **Сценарии использования** | Тестирование, временные сессии| Продуктивная работа, долговременное хранение |
| **Структура на диске**  | Отсутствует                      | `data/*.json` или `data_csv/*.csv` + `*_schema.json` |
